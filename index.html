App Inventor Renk Kodları (Doğru)

  • 🟡 Sarı → Event (when), Control (if/else, for each)
  • 🟢 Yeşil → Component setter/getter (set/get TextBox.Text)
  • 🟣 Mor → Component method call (call Player.Start)

  • 🟠 Turuncu → Variables (get global, get response)
  • 🩷 Pembe → Text/string blokları
  • 🟢 Koyu yeşil → Logic (true/false, =)

🔪 Split Mantığı (Sınav için Kritik!)

  • split text (pembe, Text) → metni belirli karakterden böler, liste döner
  • "istiklal.mp3" + split at "." → ["istiklal", "mp3"]
  • select list item index 1 (mavi, Lists) → 1. elemanı alır → "istiklal"
  • Böylece ListView'da uzantısız temiz ad görünür
  • join (pembe) → seçim + ".mp3" → tekrar tam dosya adı yapılır, Player'a verilir

🆚 Karşılaştırma

  • SoundRecorder: /storage/.../dosya.3gp → split at "/" → index 5
  • HTTPS URL: https://site.com/sesler/istiklal.mp3 → split at "/" → index 5
  • Bu örnek: istiklal.mp3 → split at "." → index 1
  • 📌 Hangi karakterden böldüğüne göre index seçilir

3 Adım Özet

  • 1️⃣ Böl: split text ... at "..."
  • 2️⃣ Seç: select list item index N
  • 3️⃣ Ekle: add items to list

📌 Yeni Kavram: Return Value (Sonuç Döndüren Fonksiyon)

  • Procedures kategorisinde 2 tür blok vardır:
    • to ... do → işlem yapar, sonuç döndürmez (Örnek 9, 10)
    • to ... result → işlem yapar VE değer döndürür ⭐ (bu örnek)

🔀 if / else if / else Zinciri

  • 4 farklı işlem: +, -, ×, ÷
  • Sarı if bloğunun mavi gear'ından "else if" eklenir
  • Hangi koşul tutarsa o satır çalışır, kalanlar atlanır

⚠ Hata Kontrolü (and operatörü)

  • Logic kategorisinden and bloğu → 2 koşul birden doğruysa
  • Spinner=÷ VE TextBox2=0 → Notifier ile uyarı
  • Sıfıra bölme matematik hatası, kullanıcıyı uyarmak iyi pratiktir
